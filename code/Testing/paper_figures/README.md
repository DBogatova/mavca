# Main figures (publication set)

Curated main figures supporting: *L5 apical dendritic calcium activity is high-dimensional,
sparse, mostly local, and compartmentalized across mice, with rare state-dependent transitions
into coordinated global recruitment.* (Exploratory figures remain in scape-data/figures/.)
Generated by code/Extra/make_main_figures.py. PNG (200 dpi) + vector PDF.

- **Figure1_independence** — A high dimensionality per FOV; B weak pairwise correlation (real vs
  contaminated); C PCA cumulative variance (real slow vs contaminated PC1≈90%); D independence
  robust across 4 mice. (Anchor result; contaminated 0416 run1 = hatched negative control.)
- **Figure2_hotspots** — A Lorenz curves; B event-count Gini; C event share of top 5/10/20% masks;
  D hotspot stability (1st vs 2nd half). (Sparse, hotspot-concentrated activity.)
- **Figure3_footprints** — A footprint-size histogram (mostly 1–2 masks); B local/global event
  fractions; C multi-mask motif recurrence vs shuffled null (p=0.003); D example 0508 footprints.
- **Figure4_state_grammar** — A global Ca @ movement onset; B global-event probability around onset
  (pre-onset rise; descriptive); C global-event fraction by state; D local vs global rate by state.
  (0508-specific; movement shifts grammar toward global recruitment.)
